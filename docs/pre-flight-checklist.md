# Pre-flight checklist

Confirm every line before running the install. Each item maps to an observed failure when skipped.

## Accounts and access

- [ ] The organization has its own **Claude account** (Pro, Team, or Enterprise) that can add custom skills and connect integrations. Install into *their* account, not a consultant's.
- [ ] The organization has an **Airtable account** (Free is fine to start).
- [ ] Airtable is connected to Claude (Settings, then Connectors) with **Full / Workspace access**, not access to selected bases. Base creation requires workspace scope; narrower access halts the install at its first check with a confusing permissions message.

## The seed document

- [ ] `template/Org-Seed-Template-BLANK.md` is filled out, or the operator has 30-45 minutes to be interviewed live instead.
- [ ] All ten **★ REQUIRED** fields are answered: A5 stage posture, D1 search geography, E1 programs with maturity, I1 budget, I3 award bands, M1 funding priority order, M2 fit criteria, M4 durable rules, M5 loan posture, M6 recurring eligibility traps.
- [ ] Answers are honest about the org's stage. The system enforces whatever posture you write; an inflated posture produces inflated claims everywhere downstream.
- [ ] Nothing personal or regulated is in the document (see its opening warning): no ID numbers, payment details, health information, or personally identifying data about people served.
- [ ] The grants history sections (H1-H5) are as **complete** as you can make them, including your funder/donor list and any funder restrictions. A partial baseline means the scan may re-pitch funders you already evaluated.

## Timing and people

- [ ] You have ~15 minutes for the install thread, started when you have NOT already used Claude heavily that day (one install uses a good portion of a day's usage on a Pro plan).
- [ ] The **operator** is identified (seed template N3): the person who will promote grants and manage the pipeline day to day. Ideally they run the install themselves.
- [ ] You know the base name you want (N2).

## After the install (know what's coming)

- [ ] You'll be handed **five skills** to save. Save all five in one sitting; if replacing older versions, **uninstall the old one first**, then save the new one.
- [ ] The installer ends by naming your next step (normally a first prospect scan). An install that ends without a named next step is not finished; ask.
